# CodeHire
CodeHire is a personalized job discovery platform designed for computer science students. CodeHire curates job listings that align with user's skills, experience, and preferences to find roles that best suites each user. 

## Description
### How CodeHire Works
#### 1. Select your skills and preferences
Create an account and choose the programming languages you know, the roles you're interested in, and your experience level.

#### 2. Get tailored job reccomendations
CodeHire filters and recommends job postings using skills your relevant interests and skill—removing noise for irrelevant results.

#### 3. Explore roles with confidence
View clear job requirements, skill matches, qualifications, and direct links to apply—all from your profile before applying.

#### 4. Apply straight away
Save time compiling and save your top results for later, then use our tracker to stay organized.

## Getting Started

### Build

Run ```pnpm run build```

### Run

To run the web application:

```bash
cd .\src\Web\
dotnet watch run
```

Navigate to https://localhost:3000. The application will automatically reload if you change any of the source files.
